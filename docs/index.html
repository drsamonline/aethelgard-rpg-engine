The engine that ships as plain files.

Aethelgard Engine is what runs Aethelgard: Chronicles of Fate — a deep single-player fantasy RPG in the browser. There is no bundler, no framework and no package to install: just HTML, CSS and ES5-ish JavaScript, loaded in script order, fully offline.

What's inside — engine decisions, not accidents

Zero build, zero dependencies

ES5-ish IIFEs loaded in script order. Nothing is imported, bundled or transpiled. Open the folder over any static host and it runs.

Data and logic kept apart

Everything under js/data/ is pure data with no side effects — which is exactly what makes a mod simple: it supplies the same shapes and they merge.

Small enough to read end to end

447 functions, no duplicate definitions, no parse failures — checked by tools/static-audit.py on every run rather than asserted in prose.

Offline by construction

A service worker and a manifest, so the game installs to a phone and keeps working with the network off. Nothing on this page loads from another origin either.

How it loads

Script order is the dependency graph. That is the whole architecture, and it is why the folder can be dropped on any static host:

  1. js/core.jsthe loop, the state
  2. js/data/pure tables
  3. js/systems/combat, saves
  4. js/ui/panels, input
  5. js/main.jsstarts it

What it refuses to do

  • No bundler. Nothing to install before you can read the code.
  • No framework. The DOM is driven directly, not through a virtual one.
  • No transpiler. ES5-ish on purpose, so it runs where it is opened.
  • No network at runtime. No CDN, no telemetry, no account.
  • No duplicate definitions. Audited, not promised.
  • No mac build. Windows, Linux and Android — that is the list.

Run it

# nothing to install — the engine is plain files
git clone https://github.com/drsamonline/aethelgard-rpg-engine.git
cd aethelgard-rpg-engine
python3 -m http.server 8080
# open http://localhost:8080 — that's the whole build

# every module is checked and exercised with plain Node
node --check js/core.js
node tools/verify.js      # PASS — tabs, actions, combat, save, both campaigns
python3 tools/static-audit.py .   # 447 functions · 0 duplicates · 0 parse failures
